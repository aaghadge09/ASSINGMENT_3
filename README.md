Python Math & Factorial Program

This project is a Python-based console application that demonstrates the use of recursion and the math module to perform common mathematical calculations.

It is designed for beginners to understand function calls, recursion, user input handling, and built-in Python libraries.

✨ Features
🔢 Factorial Calculation (Using Recursion)

Calculates the factorial of a number

Uses a recursive function

Demonstrates base case and recursive case clearly

📐 Mathematical Calculations (Using math Module)

Square root of a number

Natural logarithm (log base e)

Sine of a number (in radians)

🛠️ Concepts Used

Python functions

Recursion

Conditional statements (if-else)

User input (input())

Type conversion (int, float)

Python built-in math module

Console output formatting

🚀 How the Program Works

The user enters an integer to calculate its factorial.

The program uses a recursive function to compute the factorial.

The user then enters a number for mathematical operations.

The program calculates:

Square root

Natural logarithm

Sine value

All results are displayed on the console.

📌 Example Output

For input:

Enter your number: 5


Output:

The Factorial of 5 is 120


For input:

Enter your number: 25


Output:

Square root: 5.0
Natural logarithm: 3.2188758248682006
Sine value: -0.13235175009777303
